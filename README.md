## 🚀 Overview
Apprelab is a premium digital ecosystem designed to unify **Learning**, **Mentorship**, and **Hiring**. This repository contains the high-fidelity **Waitlist Landing Page**, engineered to capture interest and showcase the platform's vision before the full product launch.

Our mission is to eliminate "Tutorial Hell" by placing learners directly into real-world WorkLabs supervised by industry experts.

## ✨ Specialized Landing Pages
To provide a comprehensive view of the ecosystem, we've implemented detailed personas and resources:
- **[Features](src/pages/Features.tsx)**: Deep dive into micro-courses and WorkLabs.
- **[How It Works](src/pages/HowItWorks.tsx)**: The step-by-step journey from enrollment to employment.
- **[For Learners](src/pages/Learners.tsx)**: Tailored acquisition funnel for students.
- **[For Mentors](src/pages/Mentors.tsx)**: The value proposition for senior technical talent.
- **[For Businesses](src/pages/Businesses.tsx)**: Solving the hiring crisis for SMEs.
- **[Resources](src/pages/Blog.tsx)**: Integrated Blog and Help Center.

## 🎨 Design Philosophy
The site follows a **Premium Dark-Theme Aesthetic**:
- **Color Palette**: Deep Midnight Blue (`#010A45`), Golden Highlight (`#FFD93D`), and Crisp White backgrounds.
- **Typography**: Poppins for a modern, professional feel.
- **UI Components**: High-border-radius containers (`35px-40px`), smooth floating animations, and glassmorphism Navbar.

## 🛠 Tech Stack
- **Framework**: [React 18](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Material UI (MUI)](https://mui.com/)
- **Icons**: [MUI Icons](https://mui.com/material-ui/material-icons/)
- **Deployment**: Configured for [Vercel](https://vercel.com)

## 📦 Getting Started

1. **Clone & Install**
   ```bash
   git clone <repository-url>
   cd Apprelab_landingpage_frontend
   npm install
   ```

2. **Run Locally**
   ```bash
   npm run dev
   ```

3. **Build**
   ```bash
   npm run build
   ```
